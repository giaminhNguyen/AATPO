## Implemented
- `cli/windows_launcher.py`: argv-only launch, prompt on stdin (UTF-8), 2 MB output cap with continued draining, timeout, cancel, `taskkill /T /F` tree kill, `.cmd/.bat` via `cmd.exe` with an argument allowlist.
- `cli/codex_adapter.py`, `claude_adapter.py` (read-only templates), `gemini_adapter.py` (detection-only skeleton), `parsers.py` (strict), `probe.py` (local-only readiness persisted to `provider_registry`).
- `agents/session_manager.py` + migration 002: exact provider-session resume when supported, otherwise/if it breaks an explicit fallback session (`generation`, `supersedes_session_id`, `fallback_reason`, brief). A run never changes Task state.
- `agents/smoke.py`: consent-gated read-only request (service layer refuses without `consent=True`).
- GUI: `Cài đặt` page (status per provider in Vietnamese, re-check, consent dialog, Stop, collapsible technical details), `BackgroundJobs` asyncio-thread → Qt signal bridge (UI never blocks).
- `telemetry/redaction.py`; `docs/cli_compatibility.md`.
