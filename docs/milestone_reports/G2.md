# G2 — Vietnamese conversation + scope approval

**Status: ACCEPTED** against the G2 pass criteria (core + GUI tested; real Claude used for intent classification). Caveat: GUI was driven by tests/scripts, not by a human at the keyboard.

**Environment:** Windows 11 Pro 10.0.26200 · Python 3.13.14 · PySide6 6.12.0 · Claude Code 2.1.299 (real, read-only, scratch folder)

## Implemented
- `customer/`: `text.py` (sanitize/fold), `intent_router.py` (rule proposer + optional LLM proposer, Pydantic-validated), `analyst.py` (one question), `scope_advisor.py` (MUST/SHOULD/LATER/DROP, Tiết kiệm vs Cân bằng, XS–XL, no invented prices), `representative.py` (`ChatService`: history per project, deterministic action policy), `llm_ask.py`.
- `office/approvals.py`: exact action + project + work order + scope version; stale/superseded/duplicate decisions rejected; the only path to `SCOPE_CONFIRMED`.
- Migration 003 (messages, scopes, features, approvals, work-order kind/parent/brief). `SessionManager` refuses work for an unapproved product/change work order (`ScopeNotApproved`).
- GUI: working chat (background job, quick-reply chips, history reload per project), **Cần bạn quyết định** inbox with scope detail and confirm dialog, work-order list, header/nav counters, Settings toggle for LLM understanding (consent-gated).
