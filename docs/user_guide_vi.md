# Hướng dẫn sử dụng AATPO (bản đang phát triển)

1. **Mở phần mềm** (hiện chạy từ thư mục phát triển; bản `.exe` sẽ có ở bước G5).
2. **Chọn dự án:** mục **Dự án** → *Mở dự án có sẵn…* hoặc *Tạo dự án mới…* → xác nhận tên và thư mục. Có thể bật *tự động lưu lịch sử phiên bản* (khuyên dùng).
3. **Giao việc:** mục **Văn phòng AI**, gõ bằng tiếng Việt, ví dụ *“Tôi cần làm ứng dụng quản lý kho đơn giản”*. Trợ lý hỏi một câu; bạn có thể bấm *Tôi chưa biết, hãy đề xuất*.
4. **Duyệt phạm vi:** mục **Cần bạn quyết định** → xem hai phương án *Tiết kiệm* / *Cân bằng* → bấm **Đồng ý — …** hoặc **Không đồng ý**. Nhắn “đồng ý” trong ô trò chuyện **không** có hiệu lực.
5. **Trợ lý AI:** mục **Cài đặt** cho biết Codex / Claude Code đã sẵn sàng chưa. Việc gửi dữ liệu tới dịch vụ AI luôn hỏi bạn trước.

Hiện chưa có: lập kế hoạch, thực hiện công việc, báo cáo kết quả (các bước G3–G4).
